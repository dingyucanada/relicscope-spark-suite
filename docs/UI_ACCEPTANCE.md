## 1. 结论

本地确定性演示界面通过桌面、390 px 窄屏和完整 P01 工作流验收。v1.1 媒体工作台已展示图片/视频标签、质量、指纹、复拍比较、时间轴、结构化观察与 Next Best Observation；同一 API 的真实 JPEG/MP4 闭环由 `scripts/media-smoke.py` 完成。界面持续保留 `DEMO/SYNTHETIC` 和非真实鉴定结论边界。

Chrome 扩展当前未开启“允许访问文件网址”，因此 Codex 自动化不能代替操作者在系统文件选择器中选本地文件；标准文件控件、启用逻辑和 DOM/JSDOM 流程已验证。此限制来自验收工具权限，不是应用上传接口错误。正式路演前仍需手动选择一张图片和一段视频做一分钟复演。

本记录不代表双 Spark 实机验收。OpenSpec 任务 9.4 仍因缺少两台 Spark 固定私网 IP 和操作权限而待执行；当前不得声称双 Spark 实机运行、跨节点模型调用或无公网流量已经验证。

## 5. 响应式与可访问性检查

- 桌面与 390 px 视口均保留首屏免责声明和核心工作流入口；窄屏实测 `innerWidth=390`、`scrollWidth=390`。
- 初始态隐藏尚无数据的科学命题、知识、主动检测、证据和报告区；建档、媒体分析和可比较复拍分别触发对应内容展开。
- 桌面端主工作区采用左侧建档 / 科学状态、右侧媒体入口的非拉伸布局；390 px 下按操作顺序单列，不再出现同一网格行造成的大片空白。
- 390 px 证据图使用双列纵向布局并随断点重排，完成态 14 个节点保持 10 px 标签字号且页面无横向溢出。
- 表单使用原生 `input`、`select`、`textarea`、`button` 和关联标签；主要操作可由键盘聚焦。
- 样式定义统一 `:focus-visible` 指示，不依赖鼠标悬停表达状态。
- 长 SHA-256、模型名和知识版本采用可换行/截断并保留完整标题的展示方式。
- 加载、禁用、成功、失败、降级和结算状态具有文字，不仅依赖颜色。

本次未进行屏幕阅读器专项审计、浏览器矩阵或色觉模拟；这些项目不应从当前记录推断为已通过。
