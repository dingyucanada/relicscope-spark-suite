# 图片 / 视频结构化报告 Demo 验收清单｜v1.1.0

验收状态：**本机软件核心路径通过；浏览器人工选文件待现场一分钟复演；双 Spark 实机待补证**  
验收环境为 macOS 本地回环、`single-degraded`、无本地 VLM。真实媒体烟雾脚本、自动测试、浏览器渲染和重启持久性均已执行；两台 DGX Spark、真实模型和真实传感器仍未验收。

## 1. 发布门槛

v1.1.0 的本机软件候选包使用以下四类证据：

1. 自动化测试、静态检查和报告模式验证；
2. 浏览器入口、状态与报告流程记录，以及同一 API 的真实 JPEG/MP4 烟雾验收；
3. 重启后会话、媒体哈希、证据图和报告仍可读取；
4. 能力边界、模型降级和 `DEMO/SYNTHETIC` 标签检查。

标准文件选择控件已经在 Chromium 和 390 px 视口呈现；Codex 的 Chrome 扩展未开启“允许访问文件网址”，因此自动化工具不能替用户选择本地文件。该权限只影响自动化验收，不影响用户手动选择。正式路演前仍应由操作者完成一次图片和视频人工选择复演。

“双 Spark 实机通过”还需要两台目标设备上的网络、GPU、真实模型、断网运行和跨节点追溯证据。开发电脑或单机结果不能替代。

## 8. 模态与数据标签检查

| 情形 | 必须显示的状态 |
|---|---|
| 用户真实上传图片/视频 | `USER_SUPPLIED` / `RAW_CAPTURE` 或等价真实输入来源 |
| 内置知识、样例、仪器回放 | `DEMO/SYNTHETIC` |
| 本地 VLM 实际完成调用 | 实际模型、节点、运行标识和成功状态 |
| 模型未配置或失联 | `DISABLED` / `DEGRADED`，不得出现伪造模型输出 |
| Raman / XRF / HSI 回放 | `DEMO/SYNTHETIC REPLAY`，不得称真实实测 |
| UV/NIR/RTI/3D/X-ray/CT/TL 未接入 | `RECOMMENDED`、`ADAPTER_READY` 或 `PHASE_2` |
| Gold Dataset / Counterfeit Corpus 未建立 | `PLANNED`，不得用演示知识冒充 |

## 10. 禁止的签收表述

在相应证据完成前，不得写入：

- “双 DGX Spark 已完成实机部署/验收”；
- “能够仅凭图片或视频鉴定真伪/年代/窑口”；
- “已完成 Raman、XRF、HSI、X-ray、CT 或 TL 真实检测”；
- “对象科学指纹等同于法律防伪证书”；
- “演示知识已经构成 Gold Dataset 或 Counterfeit Corpus”；
- “异常候选等同于伪造、修复或现代材料”。
