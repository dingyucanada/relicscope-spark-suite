# RelicScope V2：运行时边界与 NVIDIA 技术映射

> 当前状态：`CODE_VERIFIED / DEPLOYMENT_READY`
> 尚未完成：客户 DGX Spark、目标 Android Scout 与真实业务数据的现场验收

## 1. 本文件回答什么

本文件区分三类事实：当前仓库已经实现的能力、准备在首台 DGX Spark 部署的运行路径，以及需要真实设备、数据或机构流程后才能成立的长期能力。技术名称出现在架构中，不代表组件已经安装、性能已经验证或领域效果已经得到证明。

## 4. 首台 Spark 的基线选择

生产试运行首选 Qwen3.6-35B-A3B 与 NVIDIA VLM NIM `1.7.1-variant`，原因是 NVIDIA 已为该组合提供 DGX Spark 专用 ARM64 profile，并提供标准化 OpenAI-compatible 接口。首阶段配置为：

- 图片输入；视频关闭；
- `enable_thinking=false`，减少不必要的推理开销和不可控输出；
- JSON schema 约束和服务器端语义复核；
- 单并发、有界超时和重试；
- profile、模型名称、容器 digest 与源码提交共同冻结；
- 准备完成后关闭模型下载和遥测，运行容器不携带 NGC 凭据。

该选择是工程风险最低的试运行基线，不代表模型已经通过古陶瓷领域准确性验证，也不代表它在所有指标上优于其他模型。

Qwen3.8 可作为中文质量候选；Nemotron 3 Nano Omni 可作为原生视频/音频候选；vLLM 保留为模型研发、定制量化和兼容回退路径。三者都必须在同一冻结输入和评分标准下完成现场 A/B，不能在未验证时取代主模型。

## 6. 第二台 Spark 的边界

一台 Spark 必须独立完成 Scout 上传、任务持久化、模型推理和结果返回。第二台机器可以在不同阶段承担：

- 相同冻结版本的人工切换备用；
- Qwen3.8、Nemotron 或其他候选模型的隔离 A/B；
- LoRA/PEFT、批处理、离线索引或回归评测；
- 业务量增加后的独立任务队列；
- 单机容量不足且测量证据充分时的分布式推理。

两个 Spark 不共享内存，也不会自动组成一张 256GB GPU。跨机部署需要另行解决网络、数据同步、队列归属、凭据、故障切换、恢复点和性能验证。V2 不预设两台机器永久固定的推理与控制职责。

## 7. 数据与知识边界

- 公开仓库只包含源码、演示资产和安全导入工具；真实客户数据不进入 Git、构建上下文或发布包。
- 任务媒体、SQLite、报告、凭据、备份与 NIM cache 位于不同受控目录，按各自保留和恢复策略管理。
- 没有参考库时，基础流程继续运行，并明确记录 `reference_library_used=false`。
- 导入的目录名、文件名或说明文档不自动成为事实标签；授权、对象归并、视角和领域结论需要人工核对。
- 检索相似度只表示特征空间中的相关性，不自动证明同一实物、真伪、年代、窑口或价值。
- 参考库、负向案例和向量索引必须绑定来源、许可、版本、模型身份、阈值和撤权状态。

## 8. 科学与结论边界

- 模型输出是“可见观察”和“候选证据”，不是鉴定证书。
- RGB 图片或视频不能生成 Raman、XRF、HSI、X-ray、CT、TL 等科学测量。
- 异常热图表示相对某一参考分布的偏离，不等于伪造或年代判断。
- 哈希与审计记录有助于发现运行记录的变化，不能证明原始输入本身真实，也不能替代机构数字签章和可信时间戳。
- 没有真实仪器、校准、参考物、重复性、独立样本和专家盲评时，不得把回放或模型推断写成科学实测。
- 真伪、年代、窑口、作者、价值与法律责任保持 `NOT_ASSESSED`，除非未来由具备权限的机构流程和证据状态明确改变。
- 低质量、分布外、证据冲突或模型不可用必须进入拒绝、补拍或专家升级路径，不能静默生成确定性结论。

## 9. 状态升级条件

从 `DEPLOYMENT_READY` 升级为 `HARDWARE_VERIFIED`，至少需要：

1. 在目标 DGX Spark 固定 Git commit、NIM 容器 digest、profile、served model 和配置摘要；
2. 完成真实 Scout 多图任务，保留成功模型运行证明；
3. 记录冷/热启动、1/3/5 图、并发、峰值统一内存和连续运行结果；
4. 验证模型端口不暴露、准备后断公网运行、凭据撤销和日志边界；
5. 完成低质量、模型离线、重启、低磁盘、备份恢复和 Android 真机测试；
6. 由客户或现场负责人签署验收记录。

领域准确率、参考库识别率或科学鉴证能力需要另一套 `DOMAIN_VALIDATED` 证据，不能由硬件验收代替。
