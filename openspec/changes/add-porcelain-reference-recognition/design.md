## Context

本变更面向单台 DGX Spark 的本地古陶瓷演示。参考规模约为 50 件、每件至少 5 图，向量总量约 250 至 500。该规模不需要复杂向量数据库；影响可信度的主要因素是照片质量、视角协议、训练/测试泄漏、开放集阈值和假货标签依据。

## Goals / Non-Goals

### Goals

- 对参考库内器物给出可校准、可拒绝、可追溯的同件候选。
- 对库外输入给出相似参考、差异、反证信号和下一步采集建议。
- 支持多张查询照片并量化视角覆盖。
- 将参考库、假货库、向量模型、阈值和结果绑定到不可变版本与哈希。
- 完全本地运行，模型不可用时明确停止身份识别，不用低维演示指纹冒充生产识别。

### Non-Goals

- 仅凭照片裁决真伪、年代、窑口、作者、价格或法律状态。
- 在没有真实冻结测试集的情况下宣称识别准确率。
- 以网页抓取图片或无授权资料替代藏品所有者提供的多视角样本。
- 首版引入需要长期运维的外部向量数据库。

## Decisions

### 1. 参考库、假货库和查询会话三域隔离

参考器物记录使用稳定 `artifact_id`；照片记录使用稳定 `image_id`，绑定 `artifact_id`、视角、文件 SHA-256、采集信息、许可与审核状态。假货资料位于独立空间，另含 `label_basis`、依据来源、审核人、置信级别和争议状态。查询会话只能引用两个库的发布版本，不能修改它们。

正式参考库发布门槛为 50 件，每件至少包含正面、背面、侧面、口沿/俯视、底足/款识五类视角。无法拍到底足或款识时必须明确记录缺失原因，且该对象不能用于宣称五视角正式验收。

### 2. Qwen3-VL-Embedding-2B 负责图像向量，生成模型不参与分数计算

独立本地嵌入服务按照固定英文任务指令对参考图和查询图编码，返回归一化向量、模型来源、不可变 revision、输入 SHA-256 和输出 SHA-256。生成式 Qwen3-VL 只负责可见观察和报告语言；它不得产生或覆盖检索分数。

模型端点不可用、模型身份不一致、向量维度不同或任一向量含非有限值时，正式身份识别 fail closed。现有 8 维图像指纹继续用于质量提示和确定性测试，不作为正式同件识别替身。

### 3. 50 件规模采用精确余弦扫描

索引保存每幅参考图的单位向量和器物级聚合信息。查询时执行精确矩阵乘法，得到图像级候选，再按器物聚合。该结果同时作为未来 cuVS/近似索引的 ground-truth 基线。仅当参考图数量增长到精确扫描造成可测延迟时，才启用 cuVS CAGRA/IVF 等后端；切换前必须用精确结果测召回率。

### 4. 同件候选使用多门槛状态机

器物级分数至少包含：最佳视角相似度、查询图对该器物的平均 Top-N 相似度、多视角一致性、查询质量、视角覆盖、Top-1 与 Top-2 间隔。决策状态为：

- `KNOWN_ARTIFACT_CANDIDATE`：绝对分数、间隔、质量和覆盖均通过校准门槛；
- `RELATED_REFERENCES_ONLY`：存在相关参考，但不能确认同件；
- `OPEN_SET_NO_MATCH`：没有候选达到相关性下限；
- `INSUFFICIENT_CAPTURE`：输入质量或视角不足；
- `CALIBRATION_REQUIRED`：索引缺少冻结校准记录；
- `EMBEDDING_UNAVAILABLE`：正式嵌入模型不可验证。

`KNOWN_ARTIFACT_CANDIDATE` 仍表示参考库身份候选，不表示真品。界面必须提供“候选同一件”“相似参考”“真伪未裁决”三个独立字段。

### 5. 假货库只产生反证信号

查询同时检索参考器物空间与假货空间。报告展示双方 Top-K、分数差、假货记录的审核状态、具体相似范围和标签依据。只有专家审签、无未决争议且获准用于 `COUNTERFEIT_CROSS_VALIDATION` 的记录可进入正式负向索引；`SUSPECTED`、存在争议或依据不完整的记录在导入时排除。任一命中均不得自动输出“假货”。

### 6. 阈值由冻结评测产生

校准工具要求参考库中的每件实物都有独立复拍查询，并使用库外真实器物和假货样本作为负例。复拍媒体按文件哈希与建库原图隔离；默认至少覆盖 50 个唯一实物和 20 个开集查询。输出至少包含 Top-1、Top-5、开放集 FAR、FRR、每视角召回、阈值、样本清单哈希和模型 revision。阈值不能直接从同一张入库图片与自身匹配中估计。

在没有库外负例或专家复核标签时，系统保持 `CALIBRATION_REQUIRED`，不允许通过配置文件手写一个阈值后宣称准确率。

### 7. 报告采用确定性骨架与受限模型摘要

应用先生成不可变识别证据包，包括输入、质量、模型、索引版本、候选、分数分解、拒识理由、假货交叉验证、局限和建议补拍。可选本地生成模型只能在该结构上生成中文摘要；若摘要改变决策状态、引入未知引用或给出真伪结论，系统拒绝接纳摘要。

## Risks / Trade-offs

- 仅 5 张照片可能无法覆盖局部纹饰和拍摄条件变化：演示最低 5 图，推荐 8 至 12 图并保留环绕视频。
- 同一器物的近重复照片会造成虚高成绩：按拍摄批次分组，冻结测试必须来自独立复拍。
- 假货标签可能存在争议：强制保存依据、审核等级和争议状态，报告逐条展示。
- 嵌入模型善于语义相关性但未针对古陶瓷同件识别校准：保留低层局部特征/几何复核接口，并用真实样本 A/B 后决定是否加入 reranker 或专用微调。
- 两个 GPU 模型并存增加内存压力：嵌入模型限制并发和显存比例，生成模型继续单候选常驻；实机预检记录峰值内存。

## Migration Plan

1. 先发布空库状态、模板和严格校验器。
2. 在 Spark 缓存固定 revision 的嵌入模型并启动内部端点。
3. 导入 50 件资料，构建不可变索引并输出问题清单。
4. 使用独立复拍和库外样本生成校准记录。
5. 通过 API/UI 运行库内、库外、假货近邻三类冻结场景。
6. 经专家签字后发布 `demo-v1` 库版本；历史版本只读保留。
