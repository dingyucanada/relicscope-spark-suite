## Purpose

建立来源、许可、视角、审核和完整性均可追溯的古陶瓷参考样本库及假货反证库，为本地识别和报告提供冻结输入。

## ADDED Requirements

### Requirement: 正式演示参考库满足 50 件多视角门槛

系统 SHALL 仅在一个发布版本包含恰好或不少于 50 件有效参考器物，且每件至少具有正面、背面、侧面、口沿或俯视、底足或款识五类有效照片时，将该版本标记为正式演示参考库。每张照片 SHALL 绑定器物标识、视角、MIME、尺寸、文件 SHA-256、拍摄批次、来源、许可和审核状态。

#### Scenario: 发布合格参考库
- **WHEN** 一个候选版本包含至少 50 件器物且所有器物均满足五类视角、来源和审核要求
- **THEN** 系统生成不可变版本标识和内容集合哈希，并允许该版本进入正式演示校准

#### Scenario: 任一器物缺少规定视角
- **WHEN** 候选版本中任一器物缺少规定视角或存在未通过质量门控的必需照片
- **THEN** 系统拒绝将该版本标记为正式演示参考库，并逐项返回器物、缺失视角和问题文件

### Requirement: 参考资料入库执行完整性与权属校验

系统 MUST 拒绝目录越界、符号链接越界、MIME 与内容不符、SHA-256 不匹配、重复标识、跨器物重复文件、缺失许可或来源不明的记录。系统 SHALL 保留许可用途、访问范围和审核状态，且不得把占位或合成记录标记为真实藏品。

#### Scenario: 文件内容与清单哈希不一致
- **WHEN** 照片实际 SHA-256 与清单声明不同
- **THEN** 导入失败且该文件不进入任何可检索索引

#### Scenario: 合成样本尝试标记为真实
- **WHEN** 数据级别为 `DEMO/SYNTHETIC` 的照片或器物声明真实馆藏、专家确认或机构批准状态
- **THEN** 系统拒绝该记录并指出数据级别冲突

### Requirement: 假货资料具有可复核标签依据

系统 SHALL 将假货或争议资料保存在独立逻辑空间。每条记录 MUST 包含标签等级、依据类型、可定位来源、审核人、审核时间、争议状态和适用范围。没有可定位依据的记录 MUST NOT 进入反证检索。

#### Scenario: 经机构确认的假货记录入库
- **WHEN** 记录包含机构确认状态、可定位依据、合法使用许可和有效照片
- **THEN** 系统允许其作为强反证参考并在结果中保留完整来源

#### Scenario: 只有市场传闻的假货记录
- **WHEN** 记录仅包含无来源描述或不可定位的市场传闻
- **THEN** 系统拒绝其进入可检索反证库
